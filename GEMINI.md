# Panda Web Security Tools

Focused MCP server for site, email, and agent safety checks from public data.

## When to use
- Audit SPF/DKIM/DMARC or AI/SEO readiness for a domain
- Monitor website changes, scan for hidden AI instructions
- Bulk WHOIS/expiry checks or broken-link checks

## When not to use
- Scholarly citations / literature → `panda-research-tools`
- Federal money / filings → `panda-public-funding-tools`
- Sales leads / enrichment → `panda-leads-tools`

## Notes
- Requires `APIFY_TOKEN` (free Apify token). Each tool starts one Apify Actor run billed to that account.
- Prefer one or two inputs first; read the tool `summary` / `agentSummary` before widening.
